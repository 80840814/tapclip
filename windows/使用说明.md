# TagClip for Windows

把文件/文件夹路径绑定成「标签」，点一下标签就复制到剪贴板，在微信 / QQ / 邮件里 **Ctrl+V** 就能当附件发送。

## 使用方法（Windows 10 / 11）

1. 把整个 `windows` 文件夹拷到任意位置（比如 `D:\TagClip`）
2. 双击 **`启动TagClip.bat`** 运行（没有黑色控制台窗口）
3. 点「＋ 新建标签」，起个名字，添加文件 / 文件夹，保存
4. 之后在任何聊天窗口（微信、QQ、Outlook…）里 **Ctrl+V**，文件会作为附件粘贴进去

> 如果双击没反应或被杀毒软件拦截，右键 `启动TagClip.bat` →「编辑」，确认内容；或右键 →「以管理员身份运行」一次。
> 也可以右键 `TagClip.ps1` →「使用 PowerShell 运行」直接启动。

## 数据保存在哪里？

数据保存在 **`%APPDATA%\TagClip\tags.json`**（通常是 `C:\Users\你的用户名\AppData\Roaming\TagClip\tags.json`）。

- 这是系统的用户数据目录，**重启电脑、更新程序都不会丢**。
- 卸载/重装也不会丢（除非手动删掉这个文件）。
- 想备份/换电脑迁移：把这个 json 文件拷走，放到新机器的同一位置即可。

## 各文件说明

| 文件 | 作用 |
|------|------|
| `TagClip.ps1` | 主程序（PowerShell 脚本，Win10/11 自带 PowerShell 5.1 即可运行） |
| `启动TagClip.bat` | 双击启动器（隐藏黑窗口） |
| `生成启动器.bat` | 如果 `启动TagClip.bat` 丢了，双击它重新生成 |
| `安装启动器.ps1` | （可选）右键 →「使用 PowerShell 运行」，把启动项加到开始菜单/桌面/任务栏，并生成启动器 |

## 工作原理

点击标签时，把选中的文件路径以 **CF_HDROP** 格式写入剪贴板——这和 Windows 资源管理器里「Ctrl+C 复制文件」是同一个机制，所以微信/QQ/Outlook 收到的是真正的「文件」，粘贴即可发送。
